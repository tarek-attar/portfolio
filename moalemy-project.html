Moalemy Platform

Moalemy is an advanced, AI-powered e-learning platform architected to deliver localized and intelligent educational experiences. Built with a mobile-first philosophy, the platform integrates cutting-edge AI capabilities to analyze student queries through computer vision, generate dynamic mind maps, and provide personalized study insights based on historical curricula and exams.


Key technical features include a robust backend powered by Laravel, with granular access control managed via Spatie Roles & Permissions for students, instructors, and admins. The platform seamlessly integrates the Gemini API for automated text and image analysis, incorporates secure localized payment gateways, and features an intuitive dashboard for real-time tracking of student engagement metrics.

Technologies Used
